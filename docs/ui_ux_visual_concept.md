# Визуальная концепция и переработка UI/UX для RPS Battle

Этот документ содержит комплексные предложения по визуальному стилю, дизайну интерфейсов (UI), пользовательскому опыту (UX) и интерактивным эффектам игры **RPS Battle** на всех целевых платформах: Web, iOS, Android, VK Mini Apps, Facebook Instant Games и Яндекс Игры.

---

## 1. Художественное видение и арт-дирекшн

Игра должна отойти от простейших системных эмодзи (🗿, 📄, ✂️, 💥, 🏴), которые удешевляют проект и делают его отображение неконсистентным на разных устройствах. Вместо этого вводится единая графическая система на основе **кастомных 2D-карточек/фишек** с поддержкой сменяемых визуальных тем (скинов).

### 1.1. Ключевые стилистические направления (Темы)

Для вовлечения разных сегментов аудитории предлагается запустить три стартовые темы оформления, которые игрок может выбирать в настройках или открывать в магазине:

```
┌────────────────────────────────────────────────────────────────────────┐
│                          ВИЗУАЛЬНЫЕ ТЕМЫ                               │
├───────────────────┬────────────────────────────┬───────────────────────┤
│ 1. NEON CYBERPUNK │ 2. CASUAL TOON             │ 3. CLASSIC CHESS      │
│ (Основная)        │ (Для соцсетей)             │ (Для любителей тактик)│
├───────────────────┼────────────────────────────┼───────────────────────┤
│ - Темный фон      │ - Пастельные тона          │ - Деревянная доска    │
│ - Неоновое свечение│ - Объемные кнопки          │ - Фигуры под резьбу   │
│ - Хром и стекло   │ - Живые персонажи          │ - Мраморные детали    │
│ - Синий vs Розовый│ - Яркие цвета              │ - Черно-белый контраст│
└───────────────────┴────────────────────────────┴───────────────────────┘
```

1. **Neon Cyberpunk (Основная тема по умолчанию):**
   * **Эстетика:** Футуристичный киберпанк. Глубокий темно-серый/синий фон (Glassmorphism-карточки с эффектом размытия заднего плана).
   * **Цветовая палитра:** Игрок (Сияющий Неоновый Синий `#00E5FF`), Оппонент (Пылающий Неоновый Розовый/Красный `#FF007F`), Нейтральные элементы (Электрический Фиолетовый `#7000FF`).
   * **Фигуры:** Стилизованные голограммы жестов внутри футуристических чипов.
2. **Casual Toon (Семейная/Мультяшная тема):**
   * **Эстетика:** Яркая, дружелюбная графика в стиле Clash Royale.
   * **Цветовая палитра:** Теплые оттенки, мультяшный градиент. Игрок — королевский синий, оппонент — рубиновый красный.
   * **Фигуры:** Живые персонажи-олицетворения. Камень — добродушный каменный голем, Ножницы — юркий ниндзя с клинками-ножницами, Бумага — мудрый свиток-маг.
3. **Classic Chess (Интеллектуальная тема):**
   * **Эстетика:** Строгая классика для любителей шахмат и шашек. Текстуры лакированного дерева, мрамора и слоновой кости.
   * **Фигуры:** Традиционные шахматоподобные деревянные фигурки, где на щитах выгравированы символы Камня, Ножниц и Бумаги.

## 2. Адаптивная сетка интерфейса (Cross-Platform Layouts)

Интерфейс игры должен бесшовно адаптироваться под три основных формата: **Портретный (Mobile App)**, **Альбомный (Desktop Web)** и **Квадратный/Адаптивный (Social Iframe)**. 

### 2.1. Революция игрового поля (Максимальный фокус на доске)
Текущий интерфейс перегружен второстепенными элементами и огромными кнопками (см. материалы в папке [как сейчас](file:///Users/soufee/Desktop/rps-battle/rps-battle/docs/%D0%BA%D0%B0%D0%BA%20%D1%81%D0%B5%D0%B8%D0%B6%D1%81%D0%B0%D1%81)). Для концентрации на тактике вводится новый принцип распределения пространства:

* **Максимизация доски (75–80% зоны игры):** 
  * Игровая доска расширяется на **всю доступную ширину белой (рабочей) игровой зоны** экрана. Она масштабируется динамически, подстраиваясь под высоту и ширину устройства так, чтобы занимать ключевые 75–80% площади игрового экрана.
* **Миниатюризация панелей игроков:**
  * Панели (плитки) игроков с аватарами, никнеймами и таймерами уменьшаются в высоте на **40%**.
  * Они больше не занимают дефицитное место по бокам. Они располагаются **строго над игровой зоной** и растягиваются горизонтально ровно по ширине игровой доски, формируя аккуратный единый верхний инфо-бар (Scoreboard).
* **Сворачиваемый адаптивный Лог боя (Collapsible Battle Log):**
  * По умолчанию лог боя во время игры **полностью свернут** (спрятан в компактную выдвижную панель/drawer или боковую шторку). Вместо текстового лога на экране отображается только маленькая круглая иконка-индикатор (например, свиток 📜 или блокнот 📋).
  * **Адаптивное поведение сетки:** Интерфейс является резиновым (flex-responsive). При нажатии на иконку лога панель лога плавно выезжает сбоку (или снизу на мобильных), при этом **игровая доска автоматически и плавно масштабируется в меньшую сторону**, сохраняя пропорции ячеек, чтобы освободить место. При повторном клике лог скрывается, и доска мгновенно разворачивается обратно на 75–80% экрана.

### 2.2. Замена текстовых кнопок на интуитивные иконки
Вместо громоздких прямоугольных текстовых кнопок («Выйти», «Сбросить», «Начать бой», «Сдаться», «Реванш»), которые перегружают экран во время фазы расстановки и игрового процесса, внедряется система **компактных значков-иконок** с интуитивно понятным международным дизайном:

```
┌─────────────────┬───────────────────────────────┬────────────────────────┐
│ Старая кнопка   │ Новое визуальное решение (UI)  │ Смысловое значение     │
├─────────────────┼───────────────────────────────┼────────────────────────┤
│ Выйти           │ Иконка двери со стрелкой 🚪↩️  │ Выход в лобби/арену    │
│ Сбросить        │ Иконка круговой стрелки 🔄     │ Сброс расстановки      │
│ Начать бой      │ Иконка скрещенных мечей ⚔️     │ Старт сражения         │
│ Сдаться         │ Иконка белого флага 🏳️         │ Признание поражения    │
│ Реванш          │ Иконка мечей с таймером ⚔️⏳   │ Запрос повторной игры  │
│ Настройки       │ Иконка шестеренки ⚙️           │ Открытие настроек      │
└─────────────────┴───────────────────────────────┴────────────────────────┘
```
*Каждая иконка снабжена легким неоновым контуром (в Cyberpunk теме) и микро-всплывающей текстовой подсказкой (Tooltip) при удержании пальца или наведении курсора мыши.*

## 3. Тактильный UX и Анимации (Haptics & Motion)

Движение и физический отклик создают ощущение «дорогого» продукта. Мы внедряем плавные переходы через `react-native-reanimated` и тактильные вибрации через `expo-haptics`.

### 3.1. Управление перетаскиванием (Drag-and-Drop)
* **Анимация захвата:** При зажатии фигуры пальцем/мышкой:
  * Фигура увеличивается на **15%**.
  * Появляется мягкая тень (эффект «отрыва» от доски).
  * Прозрачность фигуры падает до **85%**, чтобы видеть поле под ней.
  * Клетки, доступные для хода, подсвечиваются мягким пульсирующим зеленым (или синим в теме Неон) свечением.
* **Анимация отпускания:** Если фигура отпущена над валидной клеткой, она плавно скользит туда с эффектом упругого отскока (`spring` анимация). При наведении на недопустимую клетку фигура мгновенно возвращается на исходную позицию.

### 3.2. Схема виброотдачи (Haptic Feedback)

| Событие | Тип вибрации | Цель / Ощущение |
| :--- | :--- | :--- |
| **Выбор фигуры** | `Light` | Легкий щелчок, подтверждающий фокус |
| **Перемещение фигуры** | `Selection` | Микро-отклик при фиксации на клетке |
| **Обычный бой (RPS)** | `Medium` | Удар при столкновении фигур |
| **Взрыв капкана / Взятие** | `Warning` (двойной удар) | Ощущение физического взрыва или ловушки |
| **Победа в матче** | `Success` (ритмичный паттерн) | Триумф, радость победы |
| **Поражение в матче** | `Error` (тяжелое затухание) | Фидбек об ошибке / проигрыше |

### 3.3. Визуализация боевых столкновений (Battle Overlay)
При атаке на вражескую фигуру происходит сражение. В текущей версии это текстовый лог. 
**Предлагаемый UX-сценарий столкновения:**

1. **Микро-тряска (Screen Shake):** При коллизии доска делает короткое колебание (амплитуда `5px`, длительность `150ms`).
2. **Анимация раскрытия:** Если фигуры не были раскрыты, они поворачиваются лицом к игроку (3D flip-анимация).
3. **Дуэль при ничьей (RPS Duel Overlay):**
   * Если выпадает ничья, игра переходит в режим выбора жеста.
   * Экран доски блюрится. Слева и справа навстречу друг другу вылетают карточки соперников.
   * По центру запускается неоновый таймер на **5 секунд** со звуком тиканья.
   * Игрок видит 3 крупные кнопки жестов (Камень, Ножницы, Бумага) с микро-анимацией покачивания.
   * При выборе жеста кнопка сжимается и издает сильный виброотклик. Карточка «запечатывается» замком до выбора оппонента.
   * В момент разрешения дуэли карточки переворачиваются, проигравшая фигура разлетается на мелкие осколки (эффект частиц Particle System).

## 4. Звуковой дизайн (Audio Concept)

Звук формирует атмосферу и является важным индикатором событий геймплея. Все звуки делятся на фоновое сопровождение и интерактивную озвучку событий.

### 4.1. Фоновая музыка (BGM)
* **Главное лобби:** Легкий, технологичный Synthwave или Lofi-Hip-hop. Мелодия ненавязчива, способствует размышлениям над статистикой и выбором квестов.
* **Экран подбора (Matchmaking):** Нарастающий ритм ударных (Drumbeat) с космическими падами, создающий чувство предвкушения битвы.
* **Приятный игровой эмбиент:** Для игрового экрана используется медитативный, но сфокусированный научно-фантастический эмбиент с мягкими тонами (без резких пиков). Он создает глубокое погружение и не раздражает при длительных партиях. Фоновый звук можно полностью отключить в меню настроек.

### 4.2. Интерактивная озвучка ходов и событий (Voiceovers & SFX)
* **Озвучка перемещения фигур:** Каждый совершенный ход озвучивается мягким, приятным звуком (например, глухой стук деревянной фишки о доску или технологичный щелчок).
* **Уведомление о ходе соперника:** Когда оппонент завершает свой ход, воспроизводится короткий приятный перезвон (chime) или мягкий звуковой сигнал, сообщающий, что **теперь ваш ход**. На мобильных устройствах это дублируется легким виброоткликом.
* **Звук критических событий:**
  * `sfx_combat_clash` — металлический звон мечей или скрежет при столкновении фигур.
  * `sfx_explosion` — глухой взрыв с эхом при срабатывании капкана.
  * `sfx_tie_alarm` — предупреждающий звук гонга при начале раунда разрешения ничьей.
  * `sfx_countdown` — пульсирующий звук метронома для таймера обратного отсчета.
* **Озвучка финала (Победа и Поражение):** 
  * При победе — торжественные фанфары со звоном золотых монет (`sfx_victory`).
  * При поражении — низкий, разочаровывающий гул или минорный аккорд затухания (`sfx_defeat`).

## 5. Многоязычие (Multilingual Support)

Игра ориентирована на мировой рынок, поэтому интерфейс поддерживает **8 ключевых языков**:
1. **Русский** (RU)
2. **Английский** (EN)
3. **Французский** (FR)
4. **Немецкий** (DE)
5. **Испанский** (ES)
6. **Турецкий** (TR)
7. **Арабский** (AR — с поддержкой RTL-верстки справа налево)
8. **Китайский** (ZH — упрощенные иероглифы)

* **Логика автоматического выбора языка:**
  * При запуске игра считывает язык, установленный в **профиле авторизации игрока** (из VK API, Yandex Games SDK, Facebook Instant Games SDK или Apple/Google аккаунта).
  * Если данные отсутствуют (игрок вошел как гость / без авторизации) или язык профиля не входит в список поддерживаемых, система обращается к системным языковым настройкам устройства.
  * Если и это не дало результатов, по умолчанию выбирается **Английский язык**.
  * Игрок в любой момент может переопределить язык вручную в Меню настроек.

## 6. Меню настроек (Settings Menu)

Все параметры кастомизации, аудиосистемы и языков переносятся в единый хаб настроек. Доступ к нему осуществляется через компактную иконку шестеренки (⚙️), которая всегда доступна в верхнем углу экрана (как в Лобби, так и во время матча):

* **Кастомизация визуала:** Быстрое переключение скинов доски и фигур (Neon Cyberpunk, Casual Toon, Classic Chess).
* **Локализация:** Выпадающий список для ручного переключения любого из 8 языков.
* **Управление аудио (Audio Toggles):**
  * `Фоновая музыка (BGM)` — Вкл / Выкл (полное отключение приятного игрового эмбиента).
  * `Звуковые эффекты (SFX)` — Регулятор громкости / Вкл / Выкл (звуки ходов, взрывы капканов).
  * `Голосовые уведомления` — Вкл / Выкл (озвучка переходов хода «Ваш ход / Ход соперника», сигналы триумфа/поражения).

## 7. Первоочередные задачи по редизайну UI (Quick Wins)

Чтобы быстро повысить визуальную привлекательность игры без полной переделки кода:
1. **Заменить Emoji на SVG-иконки:** Подготовить набор векторных иконок для Камня, Бумаги, Ножниц, Флага и Капкана в едином стиле (например, неоновые контуры для темы Cyberpunk).
2. **Добавить анимированный загрузочный экран:** Вместо статичного прогресс-бара использовать CSS-анимацию вращения неонового треугольника (Камень-Ножницы-Бумага).
3. **Внедрить градиенты на карточки:** Заменить сплошные серые цвета плашек `SurfaceCard` на глубокие радиальные градиенты (например, от темно-фиолетового к темно-синему).
